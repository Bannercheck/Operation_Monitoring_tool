Aynı mimari, iki kurulum

RHEL sunucu

./watchover.sh install --production

  • Docker ya da Podman, Compose ile konteynerler: dashboard, receiver, postgres, edge :443
  • İsteğe bağlı: mcp :8765, ollama, trainer
  • Kaynaklar makinenin CPU ve belleğine göre kendiliğinden
  • Sıcak ve soğuk log ayrı disklerde olabilir
  • Gece yedeği: backup-timer on

OpenShift

helm upgrade --install watchover …

  • Tek pod: dashboard + receiver, ortak veri diski
  • Ayrı PVC'ler: data, logs-hot, logs-cold; PostgreSQL kendi StatefulSet'i
  • İsteğe bağlı MCP ve Ollama pod'ları; Route'lar ve ağ kuralları
  • Kaynaklar values-performance.yaml ile; alıcı pod sınırını okur
  • Root olmadan, rastgele kullanıcı numarasıyla
