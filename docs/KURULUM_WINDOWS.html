Watchover · Windows kurulum rehberi

DASHBOARD KURULUMU · ÇALIŞTIRMA · GÜNCELLEME · WINDOWS SUNUCUYA AJAN

0. Ön koşullar

Python 3.11 veya üzeri (https://www.python.org/downloads/, kurulumda “Add python.exe to PATH” işaretli olmalı) ve Git for Windows (https://git-scm.com/download/win). Windows'ta launcher olmadığı için kurulum PowerShell ile elle yapılır.

1. Dashboard kurulumu (PowerShell)

cd $HOME\Desktop
git clone https://github.com/Bannercheck/Operation_Monitoring_tool.git watchover
cd watchover
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
pip install -e .
python -m pytest -q          # 87 passed beklenir
“running scripts is disabled” hatası alırsanız bir kez şunu çalıştırın: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

2. Çalıştırma

cd $HOME\Desktop\watchover
.venv\Scripts\Activate.ps1
$env:LIVE_PORT = "8600"
streamlit run app.py --server.fileWatcherType none

Tarayıcı http://localhost:8501 adresini açar; canlı alıcı 8600 portunda dinler. Giriş için yerleşik yönetici hesabı admin@watchover.local ve size ayrıca iletilen başlangıç parolası kullanılır; ilk girişte yeni parola istenir.

Diğer makinelerden ajan bağlanacaksa 8600 portu güvenlik duvarında açılmalıdır (yönetici PowerShell):

New-NetFirewallRule -DisplayName "Watchover receiver" -Direction Inbound -Protocol TCP -LocalPort 8600 -Action Allow
Uygulamanın kurulduğu Windows makine kendi kendini zaten izler (Sistem › Durum › Bu makineyi izle); ona ayrıca ajan kurmanız gerekmez.

3. Güncelleme (main dalından)

cd $HOME\Desktop\watchover
git pull origin main
.venv\Scripts\Activate.ps1
pip install -e .

Ardından çalışan uygulamayı kapatıp yeniden başlatın. Veriler, ayarlar ve token'lar data\ altındadır; git pull onlara dokunmaz. Uygulama içindeki Sistem › Güncelleme de çalışır; Windows'ta launcher olmadığından yeniden başlatma elle yapılır.

4. Windows sunucuya ajan kurmak

İzlenecek Windows sunucu dashboard'a log ve metrik gönderir. Token'ı Operasyon › Sunucu bağla ya da Bağlantı ayarları › Ajanlar'dan alın.

mkdir C:\watchover; cd C:\watchover
Invoke-WebRequest http://<dashboard-ip>:8600/agent/agent.py -OutFile agent.py
python agent.py --url http://<dashboard-ip>:8600/ingest --key wo_... --auto --metrics --windows-events
SeçenekNe yapar
--autoSunucudaki uygulamaları (SAP, Oracle, IIS, Java sunucuları, veritabanları…) bulur ve log dosyalarını izler
--metricsCPU, bellek, disk (varsa GPU) değerlerini gönderir
--windows-eventsSystem ve Application olay günlüklerini gönderir
--enroll-key wk_...Token yerine filo kayıt anahtarıyla kendi kendine kayıt

Kalıcı çalışması için Görev Zamanlayıcı'da (taskschd.msc) “Bilgisayar başlatıldığında” tetiklenen, SYSTEM hesabıyla çalışan bir görev oluşturup aynı komutu verin; ya da yönetici PowerShell ile:

$a = New-ScheduledTaskAction -Execute "python" -Argument "C:\watchover\agent.py --url http://<dashboard-ip>:8600/ingest --key wo_... --auto --metrics --windows-events" -WorkingDirectory "C:\watchover"
$t = New-ScheduledTaskTrigger -AtStartup
Register-ScheduledTask -TaskName "Watchover Agent" -Action $a -Trigger $t -User "SYSTEM" -RunLevel Highest
